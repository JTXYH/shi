# Shi 1.0.0

Shi is a lightweight macOS utility that temporarily blocks keyboard input and pointer clicks while you clean your keyboard and screen.

## Highlights

- Safe cleaning mode with configurable keyboard and pointer-click blocking
- Three cleaning appearances: Wipe, White, and Night Clock
- Hold both Shift keys, or hold Shift + Esc, to exit safely
- Configurable exit hold duration and maximum cleaning time
- Six interface languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, and Spanish
- Automatic first-launch language selection based on the macOS preferred language
- Signed in-app updates powered by Sparkle 2 and Ed25519
- Universal 2 support for Apple Silicon and Intel Macs

## Installation

1. Download and extract `Shi-1.0.0-macOS.zip`.
2. Move `Shi.app` to the Applications folder.
3. On first launch, Control-click or right-click `Shi.app` in Finder and choose **Open**.
4. Enable Shi under **System Settings › Privacy & Security › Accessibility** when prompted.

This release is ad-hoc signed and is not notarized by Apple. Always download it from the official `JTXYH/shi` GitHub repository. Because ad-hoc signatures do not provide a stable Team ID, macOS may ask you to enable Accessibility again after an update.

## Requirements

- macOS 14 Sonoma or later
- Accessibility permission for input blocking during cleaning mode

The accompanying SHA-256 file can be used to verify the downloaded archive. Sparkle verifies future update archives and the appcast using Ed25519 signatures.
